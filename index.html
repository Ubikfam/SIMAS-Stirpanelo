Połączenie z GitHubem bez AI

token zostaje w tej przeglądarce

Ta strona działa bez claude.ai i bez ChatGPT: czyta GitHub bezpośrednio Twoim tokenem. Token nie trafia do pliku, do repozytorium ani do nikogo poza api.github.com.

  1. Otwórz github.com → Settings → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → Ubikfam/BliSperanto. Expiration: np. 90 dni.
  3. Permissions → Repository: Issues: Read and write (zapis tylko decyzji w #50), Pull requests: Read-only. Nic więcej.
  4. Skopiuj token (zaczyna się od „github_pat_”) i wklej poniżej.
